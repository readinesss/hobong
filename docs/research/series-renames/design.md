## 2. 만들 것

### 2.1 넓게 찾기 (`src/lib/character/series.ts`)

지금의 찾기(같음 → 앞부분 → 안)를 **그대로 먼저** 돌린다(R0). 지금 표와 다른 표 어디에서도 하나도 못 찾았을 때만 아래를 차례로 해 본다. 표에 실제로 있는 이름이 늘 먼저다(`인사조직`은 '직'으로 끝나지만 R0 에서 그대로 찾는다).

- **R1 꾸밈말 떼기**: 앞의 `국가직`·`지방직`·`국가`·`지방`·`N급`(숫자+급), 뒤의 `공무원`·`직렬`·`직류`·`직군`·`직`을 더 뗄 것이 없을 때까지 뗀다. 뗀 뒤 2자 이상이고 달라졌으면 그 글자로 R0 를 다시 돌린다. (`세무직` → 세무, `지방직 교육행정` → 교육행정, `9급 사회복지직 공무원` → 사회복지)
- **R1' 줄임말 풀기**: (꾸밈말을 뗀) 글자가 줄임말 사전(2.2)에 있으면 원래 이름으로 R0 를 돌린다. (`교행` → 교육행정)
- **R2 조각 찾기**: 그래도 지금 표에서 못 찾았으면, (꾸밈말을 뗀) 찾는 글자 **안에 들어 있는** 지금 표의 직렬·직류 이름(2자 이상, 찾는 글자보다 짧은 것)을 권한다. 긴 이름 먼저 → 원문 표 순서, 6개까지. (`경찰행정` → 행정, `경찰일반행정` → 행정 · 일반행정 직류 다음에 행정… — 한 직렬은 한 번만, 가장 긴 조각으로)
  - 조각으로 찾은 것은 **짐작**이다: 상태 줄에 "이름에 든 글자로 찾았다"고 밝히고, Enter 로 저절로 고르지 않는다.
- 결과에는 어떻게 찾았는지(`how: 'as-is' | 'strip' | 'short' | 'piece' | 'none'`)와 실제로 쓴 글자(`used`)가 담긴다. 화면은 이것으로 상태 줄을 쓴다.
- 지금의 `searchSeries`·`inTable`·`counterpartOf` 의 뜻(다른 표에만 있는 이름의 안내, 짝 안내)은 바꾸지 않는다. 지금 통과하는 `tests/unit/series-search.test.ts` 의 기대는 하나도 바꾸지 않고 통과해야 한다(새 함수를 더하거나, searchSeries 가 as-is 일 때 같은 결과를 내게).

### 2.2 찾기 사전 (`data/series.json`, schema 3)

새 구역 `finder`. 법령의 이름이 아닌 말을 원문 이름으로 **이어 주기만** 한다. 여기에 든 말은 저장 키가 아니다.

```jsonc
"finder": {
  "notes": ["…무엇이고 무엇이 아닌지, 근거는 docs/DATA.md 직렬 절…"],
  "short": [
    {"say": "교행", "means": "교육행정"},
    {"say": "일행", "means": "일반행정"},
    {"say": "사복", "means": "사회복지"}
  ],
  "common": [
    {"say": ["경찰행정"], "text": "흔히 경찰청·경찰서에서 일하는 일반직 공무원을 이렇게 불러요. 인사기록에 적힌 직렬 이름으로 골라 주세요."}
  ]
}
```

- `short`(줄임말): 공무원 사이에서 굳은 줄임말 셋만. 화면에 '줄임말'이라고 밝힌다. 더 넣지 않는다(넣으려면 근거를 DATA.md 에 적는다).
- `common`(흔히 부르는 이름): 근거가 있는 것만. 지금은 `경찰행정` 하나. (꾸밈말을 뗀) 찾는 글자가 `say` 와 **같을 때** 그 설명을 안내 상자에 보인다. 조각 찾기(R2)와 직종 말(2.3)은 그대로 함께 돈다.
- **옛 이름**: `research.md` 가 부칙 원문으로 확인한 대응만, 그 직렬 항목의 `aliases` 에 넣는다(이미 있는 칸 — 예전 저장본도 맞게 된다). aliases 로 찾았을 때는 목록 글자에 지금 이름과 옛 이름을 함께 보인다(예: `형사법무 (옛 이름 검찰)`) — `SeriesHit` 에 맞은 옛 이름을 담는다. 확인하지 못했으면 넣지 않고 docs/DATA.md TODO 에 **T50** 으로 적는다(화면에서는 2.4 '직접 적기'가 받는다).
- 데이터 테스트: `say` 는 두 표 어디에도 없는 이름이어야 한다(있으면 사전이 아니라 표가 답이다). `means` 는 어느 표엔가 있는 직렬·직류 이름이어야 한다. 모든 글자는 `SERIES_KEY_RE` 형식. `common[].text` 는 copy.test 의 규칙(해요체 등)을 지킨다.

### 2.3 직종 말 (`src/lib/app/track.ts`)

찾는 글자(공백 뗀 것)에 **다른 직종의 이름**(규정 데이터 `tracks.items[*].label`, 공백 뗀 2자 이상)이 들어 있으면 그 직종이 따로 있다고 알린다.

- 지금 직종과, 직렬표가 있는 직종(seriesScope 가 있는 직종 — 다른 표 안내가 이미 맡는다)은 뺀다. 겹치면 긴 이름만(`해양경찰행정` → 해양경찰).
- 지금 표에서 **이름이 같게**(rank 0·1) 찾았을 때는 보이지 않는다. 그 밖에는 결과가 있어도 보인다(`경찰` → 철도경찰이 나오지만, 경찰공무원이 일반직으로 잘못 들어온 경우를 잡는다).
- 글: "직종에 {label}{이/가} 따로 있어요. {label} 공무원이면 …"처럼 **label 뒤에 '공무원'을 기계적으로 붙이지 않는다**('교원 공무원'). 예: `직종에 경찰이 따로 있어요. 해당하면 직종을 바꿔 주세요. 그 직종은 직렬을 고르지 않아요.` 조사는 josa().
- 단추는 이미 있는 [직종 고르기로 가기](ongotrack). 직종을 저절로 바꾸지 않는다.
- 화면 코드에 직종 id 문자열을 쓰지 않는다(이 도우미는 rules 와 CareerRules 만 받는다).

### 2.4 직접 적기 (저장 형식은 바꾸지 않는다)

법원·국회·선관위·헌법재판소처럼 두 표 밖의 직렬을 가진 사람, 그리고 '경찰행정'처럼 자기가 부르는 이름을 쓰고 싶은 사람을 위한 마지막 길.

- **'직접 적은 이름'의 뜻**: `profile.series` 가 **국가·지방 두 표 어디에도 없는**(aliases 포함) 이름. 새 칸·새 표시를 저장하지 않는다(v7 그대로, `SERIES_KEY_RE` 형식 검사 그대로). 다른 표에만 있는 이름(지방 `교육행정`을 일반직에서)은 지금처럼 '직접 적은 이름'이 아니다(숨기고 짝 안내).
- 찾는 칸에 적은 글자(앞뒤 공백을 떼고 겹친 공백을 하나로)가 ① `SERIES_KEY_RE` 에 맞고 ② 12자 이하이고 ③ 두 표 어디에도 없는 이름이면 **['{이름}' 그대로 쓰기]** 단추를 보인다. 누르면 `onchange(이름, null)`.
  - 형식에 맞지 않으면(특수문자·이모지·13자 이상) 단추 대신 까닭 한 줄("한글·영문·숫자로 12자까지 쓸 수 있어요").
  - 지금 표에서 이름이 같게 찾았으면 보이지 않는다.
- 보이는 곳: `seriesNameOf(series, scope)` 가 직접 적은 이름이면 그 글자를 돌려준다(scope 가 null 인 직종에서는 지금처럼 null). 따라서 홈 상태창·설정·카드(사용자가 켰을 때만)에 그대로 나온다. 단 **'직렬'이라는 말을 붙이지 않는다**(홈 `경찰행정`, 카드 `경찰행정` — 법령의 직렬처럼 보이지 않게. 표의 이름은 지금처럼 `행정 직렬`). 직류는 없다(null).
- 소품: 테마가 없으므로 'auto' 는 지금의 '직렬을 고르지 않았을 때'와 같다. 꾸미기에서 직접 고를 수 있다는 한 줄을 안내에 둔다.
- 목록(select)의 고른 값 표시: `{이름} (직접 적은 이름)`. 다른 표의 이름·그 밖은 지금처럼 `(목록에 없는 저장값)`.
- 안내(개인정보): "직접 적은 이름은 고치지 않고 그대로 보여요. 이름이나 기관처럼 나를 알아볼 수 있는 말은 넣지 마세요." 직접 적은 이름도 이 브라우저에만 저장한다(내려받은 임용정보 패키지에는 들어간다 — 지금 직렬과 같다).
- 도움말 한 줄: "목록에 없으면 찾는 칸에 이름을 적고 [그대로 쓰기]를 눌러 주세요."

### 2.5 화면 (`src/screens/profile/SeriesPicker.svelte` — 첫 입력의 대화·한 번에 쓰기·설정이 함께 쓴다)

자리(위에서부터): 찾는 칸 → 상태 줄(role=status, 짧게) → 안내 상자(라이브 영역 아님) → 목록.

- 안내 상자는 **하나로 쌓는다**(상자가 셋씩 겹치지 않게): 흔히 부르는 이름의 설명 → 다른 표 안내(지금 것) → 직종 말 → 그대로 쓰기. 줄 사이를 띄우고 단추는 44px 이상.
- 상태 줄 예(문구는 다듬어도 된다. 낭독이 길어지지 않게 한두 문장):
  - strip: `'세무'로 찾았어요. 1개 있어요. 아래 목록에서 골라 주세요.`
  - short: `'교행'은 '교육행정'의 줄임말이라 '교육행정'으로 찾았어요. …`
  - piece: `'경찰행정'은 직렬표에 없는 이름이에요. 이름에 든 글자로 1개 찾았어요.`
  - none: `'○○'은 직렬표에 없는 이름이에요.`(그대로 쓰기 단추가 답이다 — "다른 글자로 찾아 주세요"로 끝내지 않는다)
- placeholder 는 지금 것(예: 간호, 교육행정)을 유지한다.
- 찾는 글자는 화면에 넣기 전에 길이를 자른다(상태 줄·단추에 40자 넘게 되풀이하지 않는다). {@html} 을 쓰지 않는다.

## 3. 바꾸지 않는 것

- 저장 형식(v7), 검사, 변환. 카드·공유의 기본값(직렬은 사용자가 켰을 때만). 직류는 카드·공유에 내지 않는다.
- 직종을 저절로 바꾸지 않는다. 직렬은 여전히 선택 사항이고 계산에 쓰지 않는다.
- 소품 테마 표. 직렬 사이에 순위가 느껴지는 표시 금지.

## 4. 테스트

- 단위(`tests/unit/series-search.test.ts` 에 더하거나 새 파일): 2.1 의 예 전부, 두 표의 모든 직렬·직류 이름(158개)이 as-is 로 자기 자신을 rank 0·1 로 찾는다(회귀), `인사조직`은 떼지 않는다, `지방세`는 떼지 않는다, 1자·빈 글자·공백·40자 넘는 글자·특수문자·이모지에서 죽지 않는다, 줄임말, 흔히 부르는 이름, 직종 말(지금 직종 제외·긴 이름만·같게 찾으면 숨김), 직접 적은 이름 판정(두 표에 없음 / 다른 표에만 있음 / aliases), `seriesNameOf` 의 새 뜻, 데이터 규칙(2.2).
- 파일 묶음: 카드·결산 카드·공유 문구가 새 사전(finder)을 읽지 않는다. 화면 코드에 직종 id 문자열이 없다(기존 테스트 방식).
- e2e(새 `tests/e2e/series-find.spec.ts`):
  1. 설정 → 내 정보 고치기 → `경찰행정` → 설명·'행정' 권함·직종 '경찰' 안내·그대로 쓰기가 보인다 → 목록에서 행정을 고르고 저장 → 다시 열어도 그대로.
  2. `경찰행정` → [그대로 쓰기] → 저장 → 홈 상태창에 `경찰행정`('직렬'이 붙지 않음) → 새로 고침 뒤 그대로 → 카드에서 직렬을 켜면 카드 글에 `경찰행정` → 임용정보 패키지 내보내기·불러오기 왕복 뒤 그대로.
  3. `세무직` → 세무, `교행` → 교육행정(줄임말), 12자 넘는 글자·특수문자 → 까닭 한 줄.
  4. 말을 거는 첫 입력에서 `경찰행정` → [직종 고르기로 가기] → 직종 질문으로 가고, 돌아오면 찾는 글자가 남아 있다.
  5. 키보드만으로 1·2 를 한다. 360px 에서 안내 상자가 넘치지 않는다.
