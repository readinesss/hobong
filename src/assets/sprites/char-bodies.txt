# 호봉이 몸통 5종(최종 2차: 자세 + 크기 계단 + 단계별 깃) — 48×48, 중심 x=23.5. 앵커 8개(eyes, head, neck, handL, handR, crown, ground, chest — chest 는 가슴 배지 자리, char-deco.txt). ground 는 모두 (24,45).
# 단계는 자세로 먼저 갈린다: 껍데기에 폭 앉음 → 찹쌀떡처럼 서서 차렷 → 한 날개 번쩍 → 날개를 펴고 가슴 쭉 → 오색 부채 날개를 펴고 떠오름.
# 키(머리 꼭대기 y)는 22 → 18 → 16 → 13 → 12, 몸통 폭(외곽선 포함)은 알 22 → 솜 26 → 깃 26 → 날 28 → 봉황 30 으로 줄지 않고 자란다.
# 깃은 없음 → 흰 첫 깃(c·d·e) → 파랑 한 계열 → 오색(파랑·하늘·초록 날개, 붉은 볏·꼬리)으로 늘어난다.
# 얼굴(이마 줄무늬 3줄·볼·부리·눈 자리)은 다섯 단계가 같은 픽셀이다. 바탕 4, 그늘·줄무늬 3. 깃·볏·꼬리에는 3·4를 쓰지 않고 몸과 외곽선 0으로 갈라 둔다
# (눈 앵커에서 0을 넘지 않게 칠해도, 3·4를 통째로 바꿔도 몸만 바뀐다).
# 날개는 언제나 날개손(몸 색 팔)에 붙어 있다: 팔이 어깨에서 손끝(handL/handR)까지 한 덩어리로 이어지고, 깃은 그 팔 뒤에서 뻗는다(팔 넷처럼 보이지 않게).
# 팔은 어깨 쪽만 몸과 그늘선 3으로 이어지고(칠하기가 손까지 닿는다) 아래쪽은 외곽선 0으로 몸과 갈라진다.
# 다리 규칙(다섯 단계 공통): 몸 아래 외곽선을 닫고 다리는 그 아래에 따로 그린다 — 눈 앵커 칠하기는 다리에 닿지 않고, 다리 색(3)은 3·4 치환으로만 바뀐다.
# head 앵커는 머리 꼭대기 외곽선 줄. 볏·솜털은 그 위 5행 x19~28 상자 안. 머리 오른쪽 위(x33~46, head 위 14행)는 효과 자리라 비운다.
# handL 은 x≥9(직렬 소품이 기준점 왼쪽으로 9px까지 뻗는다). 그림은 x1~46 안에 둔다(x0·x47 비움: 카드 무대 테두리에 붙지 않게).
# crown 앵커는 금빛 깃(관)이 얹히는 자리. 볏·솜털이 형태를 가르는 솜봉이·깃봉이는 볏 위쪽(관이 볏 끝에 얹혀 그 아래 볏이 보인다), 나머지는 head 와 같다.
# neck 앵커는 부리에서 2줄 이상 떨어뜨린다(목걸이 V가 부리 밑 입처럼 읽히지 않게).
#

# 깃봉이(7급): 한쪽 날개를 번쩍 들어 퍼덕이는 자세 — 다섯 단계 중 유일한 비대칭 실루엣. 처음 돋은 깃은 흰 솜깃(c, 그늘 d, 깃 사이 e).
# 깃은 끝이 둥근 깃 세 장이 부채처럼 겹친 작은 날개(가장자리에 오목한 홈 두 개)이고 가운데 잎맥이 없다 — 잎·풀·직렬 새싹 소품과 헷갈리지 않게 흰색으로 했다.
# 오른날개손(handR)은 어깨에서 볼 옆까지 들어 올리고 날개는 팔뚝 바깥으로 펼쳐진다. 왼날개손(handL)은 아래로 내리고 날개는 팔 바깥에 붙는다(y38 아래로 늘어지는 깃 없음).
# 붉은 두 갈래 볏이 처음 돋는다. 몸통은 폭 26(머리보다 2px 넓은 배). 머그컵·도장은 들어 올린 손(볼 옆 높이)에서 '건배'·'쾅' 자세가 된다.

# 날봉이(6급): 가슴을 쭉 펴고 선 당당한 자세(대칭). 다리가 한 줄 길어졌다(4행) — 다 자란 새의 키(머리 꼭대기 y13, 몸통 폭 28).
# 날개는 덮깃(하늘 a·물빛 b) 위로 끝이 뾰족한 첫째깃 세 장(파랑 9, 아래 깃 그늘 남색 8)이 위·바깥으로 활짝 뻗는다 — 파랑 한 계열.

# 봉황(5급 이상): 오색 부채 날개를 펴고 청·적 불꽃 꼬리깃을 피운 채 떠 있다 — 발끝만 보이고 그림자와 5px 떠 있다(발바닥 y39, 그림자 y45).
# 몸통은 가장 넓고(폭 30) 가장 높다(머리 꼭대기 y12). 흰 가슴털도 가장 크다. 떠 있어서 작고 둥근 그림자(shadow-float)를 쓴다.
# 날개는 깃 세 장씩(위부터 파랑 9·하늘 a·초록 6, 끝이 둥근 깃)이 몸 색 팔에서 머리 양옆으로 V자로 솟는다. 깃끝 흰색은 없다.
# 꼬리는 엉덩이 밑(몸 아래 외곽선 바로 밑, 발 양옆)의 붉은 뿌리에서 바깥 아래로 부채처럼 퍼지는 불꽃 깃 세 장씩이다:
# 옆으로 눕는 깃(끝 x6, y40), 비스듬히 내려가는 깃(끝 x8, y44), 아래로 내려가는 깃(끝 x13, y44). 바깥 테(뿌리 윗줄·깃 바깥쪽·끝)는 붉은색 2,
# 안쪽은 파랑 9·하늘 a, 뿌리 가운데 속불은 흰색 c(4px). 위의 부채 날개와 아래의 부채 꼬리가 모래시계 실루엣을 만든다(날봉이는 V 날개 + 다리).
# 꼬리는 y37~44, 손 소품 자리(handL/handR 둘레 y29~38) 아래에 있어 결재판·도장·머그컵을 들어도 가려지지 않는다.
# 발 사이·발밑 가운데(x15~32)는 비워 두어 떠 있는 것이 보인다. 3·4(몸 색)는 쓰지 않고, 꼬리는 몸 외곽선 아래에서만 돋아 몸과 닿지 않는다.
# 날개 끝은 y13 아래(효과 자리 x33~46, y−2~11 비움), 꼬리는 아래 귀퉁이 반짝이 자리(x0~6·x41~45, y41~46)를 비운다.
