# 꾸미기 장식 — 고른 사람만 붙는다. 호봉 소품과 자리가 겹치지 않게 머리 왼쪽(pin)·가슴 오른쪽(badge)·볼(cheek)만 쓴다.
# 폭은 모두 짝수(char-items.txt 규칙). 모든 장식은 먹색(0) 외곽선을 둘러 어느 몸 색(노랑·백호 흰색·물빛·연두 …)에서도 묻히지 않는다.
# 그래도 속 색이 몸 색과 같으면 외곽선만 남아 '구멍'처럼 보이므로, 몸 색 변형마다 장식 속 색을 바꾼다:
# data/character.json custom.bodies[].decoRemap { 장식 이름: { 원래 색: 바꿀 색 } } (itemRemap 과 같은 방식, look.ts 가 장식 층의 remap 으로 넘긴다).
#   햇살(기본 노랑)  별핀·별 배지 4→c, 3→d (노란 별이 노란 몸에 묻힘 → 흰 별)
#   물빛            리본 a→9, 9→8         바다  리본 a→3, 9→2(주황 리본)
#   새싹            잎 5→4, 6→3(가을 잎)  노을  꽃 2→c(흰 데이지), 하트 2→c, c→4(흰 하트)
#
# 머리핀(pin): head 앵커(머리 꼭대기 외곽선 줄)에 붙는다. 다섯 형태의 머리통은 head 앵커 기준으로 모양이 같아서
# (몸통마다 head 앵커 y 는 다르지만 eyes = head + 8 로 머리통 픽셀이 같다) 같은 origin 으로 모두 왼쪽 위 외곽선에 걸린다
# (tests/unit/assets.test.ts 가 다섯 몸통에서 확인한다).
# 핀은 x14~22, head+0~5 줄 안에만 그린다: 볏 상자(x19~28, head 위 5행)는 head 줄보다 위라 겹치지 않고,
# 안경 윗테(head+5 줄 x18~21)와도 겹치지 않는다(head+5 줄에는 x16~17 만 쓴다). 왼쪽 첫 줄무늬(x19~20)는 일부 가린다.
# 색 픽셀은 모두 머리통(0·3·4) 위에 놓이고, 바깥으로 삐져나오는 것은 핀 외곽선(0)과 리본 왼쪽 날개 끝 1px 뿐이다.
# 층 23: 금빛 깃(22) 위에 그린다. 모자를 쓰는 기분(휴가·잠·축하, moods[].hide 의 'head')에는 핀을 숨긴다

# 목걸이 끈·명찰(x20~27)과 넥타이(x20~26)의 오른쪽 1px 띄운 곳이다: 알 (29,37)·솜 (30,33)·깃 (29,32)·날 (29,30)·봉황 (30,29)
