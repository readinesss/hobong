# 특정직 소품 — 호봉이가 왼손(handL)에 드는 정중한 일상 도구(직종 track 별). 어느 직종이 무엇을 드는지는
# data/character.json 의 custom.props[].tracks 가 정한다. 그 밖의 특정직(법관·검사 등)은 전용 소품이 없다.
# 공통: 오른쪽 끝의 노란 덩어리(위 000, 가운데 0440·0430, 아래 000)가 소품을 쥔 날개 끝이다.
# 기준점(@origin)은 그 덩어리의 왼쪽 외곽선 열·0440 줄. @attach handL @layer 25.
#
# 날개 끝 몸 색 따르기 — @skin 지시어를 붙인 소품에만, 한 가지 위치 규칙으로:
#   '기준점 오른쪽(x ≥ originX+1), 기준점 줄 위아래 2줄(|y − originY| ≤ 2) 안의 4·3 = 날개 끝 → 몸 색 치환을 따른다'
#   (src/lib/character/regions.ts skinSprite). item-folder·series-*·track-* 모두 같은 규칙.
#   그래서 소품 그림의 4·3 은 이 띠 밖(기준점 왼쪽이거나 위아래 3줄 이상 떨어진 곳)에서는 자유롭게 써도 된다.
#   (예: 손전등 렌즈·빛, 칠판 나무 테, 무전기 표시등은 띠 밖이라 몸 색을 따르지 않는다.)
# 그리지 않는 것: 보호 표장·계급장·기관 상징(참수리 등)·태극·무궁화·군 표식, 무기·방패·수갑·경광등.
# 여섯 소품 모두 밝은 색 두세 가지를 넣어 시각 무게를 맞췄다(회색만 쓰는 소품 없음).
